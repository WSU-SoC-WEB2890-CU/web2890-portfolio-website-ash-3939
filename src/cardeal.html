Cardeal Prototype

Project Overview

The Cardeal project was my first major assignment for a Portfolio course. The goal was to create a modern, responsive, and visually appealing one-page website for Cardeal, a fictional company that offers cash for cars. This project challenged me to implement Bootstrap 5 and SASS while incorporating custom design decisions to ensure the website felt unique. The project was completed in approximately two weeks, with a focus on creating a professional and functional user experience.

Methods

To build the Cardeal website, I followed a structured workflow:

  • Conducted competitor research by analyzing websites like peddle.com and carbrain.com to understand industry standards.
  • Designed wireframes and layouts using Bootstrap's grid system.
  • Customized SASS variables for colors, typography, and spacing to move beyond a generic Bootstrap look.
  • Developed and refined each section of the site, including the hero, FAQ, and testimonial carousel, while ensuring responsiveness across devices.

Tools

The primary tools and technologies used included:

  • Bootstrap 5: Provided a foundation for responsive design.
  • SASS: Allowed for efficient styling and customization of Bootstrap components.
  • HTML5 & CSS3: Ensured semantic and accessible coding practices.
  • GitHub: Version control and collaboration.
  • Vecteezy: For editing SVG images.
  • Google Fonts: Selected modern typography for a clean, professional aesthetic.

Users

The target audience was anyone looking to sell their car quickly and easily. The design emphasized simplicity, trust, and clarity to cater to users of all technical backgrounds and ensure accessibility for both desktop and mobile users.

Details and Findings

Design Decisions
I selected a modern color scheme inspired by competitor websites but adjusted it to convey trust and professionalism. Fonts from Google Fonts were paired for readability and a clean aesthetic. The layout leveraged varied column widths and flex-based styling to maintain visual interest and guide the user’s journey.

Strongest Features

  • A fully responsive hero section with an intuitive form layout.
  • A customized testimonial carousel that avoids a cookie-cutter design.
  • The FAQ section, featuring an accordion that blends usability with creativity.

Problems I Encountered and What I Learned

Challenges

  • Ensuring Uniqueness: Customizing Bootstrap styles to make the design feel unique required extra effort, particularly with components like the carousel and cards.
  • Image Optimization: Finding and resizing images that matched the color scheme while maintaining quality for responsiveness was time-intensive.
  • Equal-Height Cards: Displaying cards with dynamic content lengths evenly across all screen sizes presented technical challenges.
  • SASS Organization: Structuring SASS files for scalability was a new concept, and I had to learn how to modularize code effectively.

Solutions and Lessons

  • Experimenting with SASS variables and mixins taught me how to better manage repetitive styles and create a cohesive look.
  • I used flexbox utilities and align-items-stretch to fix the uneven card heights.
  • Testing responsiveness at various breakpoints improved my understanding of Bootstrap's grid system and media queries.

Takeaways
This project deepened my knowledge of Bootstrap 5, SASS, and responsive design. I also learned the importance of balancing creative freedom with meeting client (or instructor) expectations.

Results
The final product was a visually appealing and fully responsive website that met all the project requirements. It showcased my ability to combine design and technical skills effectively, leaving me confident in tackling more complex web development challenges.
