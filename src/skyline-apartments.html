Skyline Apartment Prototype

Project Overview

The Skyline Residences Website project involves designing and developing a fully functional website for a fictional apartment complex. The website consists of seven pages: Home, Gallery, Amenities, Floor Plans, Neighborhood, Contact Us, and a custom 404 Error page. The primary objective is to create a user-friendly, visually appealing, and responsive platform that showcases the features of the apartment complex while engaging users.

Methods

A structured workflow was followed to ensure the project's success:

  • Purpose Definition: Identified the target audience as prospective renters and highlighted the website's purpose of presenting Skyline Residences as an ideal living choice.
  • Research and Planning: Conducted competitor analysis and card-sorting exercises to prioritize content and develop a clean, intuitive structure. Created wireframes and a mood board to finalize the website’s layout and visual style.
  • Development: Each page was built and refined iteratively, ensuring responsiveness and incorporating interactive features, such as a photo carousel and map integration.

Tools

The primary tools and technologies used included:

  • Bootstrap 5: Provided a foundation for responsive design.
  • SASS: Allowed for efficient styling and customization of Bootstrap components.
  • HTML5 & CSS3: Ensured semantic and accessible coding practices.
  • GitHub: Version control and collaboration.
  • Vecteezy: For editing SVG images.
  • Google Fonts: Selected modern typography for a clean, professional aesthetic.

Users

The target audience includes prospective tenants of Skyline Residences. The website is designed to provide an easy-to-navigate interface for users seeking information about apartment features, floor plans, amenities, and the surrounding neighborhood.

Details and Findings

Design Decisions
The website’s design aimed to balance modern aesthetics with functionality. Used a calming color scheme to reflect luxury and professionalism. Created consistent layouts across pages to ensure a cohesive user experience. Leveraged animations and hover effects to enhance interactivity without overloading the interface.

Strongest Features

  • I very simple design easy to read and find information.
  • A customized banner carousel at the top that avoids a basic design.
  • The gallery has modules that pop up when the image is clicked on so you can see it better.

Problems I Encountered and What I Learned

Challenges

  • Accessibility: Ensuring all interactive elements were accessible to keyboard and screen reader users presented a learning curve.
  • Image Optimization: Finding and resizing images that matched the color scheme while maintaining quality for responsiveness was time-intensive.
  • Equal-Height Cards: Displaying cards with dynamic content lengths evenly across all screen sizes presented technical challenges.
  • SASS Organization: Structuring SASS files for scalability was a new concept, and I had to learn how to modularize code effectively.

Solutions and Lessons

  • Experimenting with SASS variables and mixins taught me how to better manage repetitive styles and create a cohesive look.
  • Optimized JavaScript and images to improve carousel performance.
  • Testing responsiveness at various breakpoints improved my understanding of Bootstrap's grid system and media queries.

Takeaways
This project enhanced my knowledge of advanced JavaScript features, SASS structuring, and accessibility principles. I also learned the importance of user feedback during testing to identify usability issues.

Results
The Skyline Residences Website is a fully functional, visually compelling, and responsive platform. Its professional design and modern features showcase my web development skills and serve as a valuable addition to my portfolio. By completing this project within the 25-hour timeline, I demonstrated my ability to manage time effectively while maintaining high-quality deliverables.
